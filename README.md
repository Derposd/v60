# V60 Brew

Android-приложение для заварки кофе в воронке V60: таймер с отметками вливаний, запись рецептов и подсказки по сохранённым рецептам.

## Установка на телефон

1. Откройте на телефоне страницу **Releases** этого репозитория → релиз `apk-latest`.
2. Скачайте `V60-Brew.apk` и откройте его. Если Android спросит — разрешите установку из этого источника.
3. Новые сборки ставятся поверх старых, сохранённые рецепты не пропадают.

APK собирается автоматически GitHub Actions при каждом пуше (workflow `Android APK`).

## Как пользоваться

- **Старт** — запускает таймер, первое вливание — **блуминг**.
- **Следующее вливание** — отмечает время каждого нового вливания. Количество не ограничено.
- После 3-го вливания рядом появляется **Закончить** — останавливает таймер.
- Случайно нажали лишний раз — «Отменить последнее».
- После остановки открывается форма: вода в каждом вливании, воронка, фильтр, помол, температура, кофе,
  зерно (название, обжарщик, происхождение, обработка, степень и **дата обжарки**), оценка и комментарий.
- **Подсказки по рецепту**: на главном экране выберите сохранённый рецепт. Таймер покажет, сколько воды влить,
  сколько должно быть на весах и через сколько следующее вливание, а за 3 секунды и в момент вливания телефон
  завибрирует. Порцию кофе можно изменить — вода пересчитается.
- Таймер продолжает идти, даже если закрыть приложение; экран во время заварки не гаснет.
- Рецепты можно искать, добавлять в избранное, редактировать и отправлять текстом.

## Сборка локально

Нужны JDK 17 и Android SDK (compileSdk 35):

```
./gradlew assembleRelease
```

Ключ подписи лежит в `app/keystore/v60.jks` — он общий для всех сборок, чтобы обновления ставились поверх.
