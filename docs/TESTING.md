# Проверка в чистой среде

## Что проверено при разработке

| Проверка | Где | Результат |
|---|---|---|
| Юнит-тесты (100 шт.): VDF, video.txt, localconfig.vdf, бэкап/откат, write-ahead-журнал, откат при ошибке посреди применения, «Откатить всё» в обратном порядке, пропуск админских наборов без прав, конфликты, твики, параметры запуска, классификатор профиля, версия драйвера NVIDIA, статистика кадров, CSV PresentMon, пинг/jitter, вердикт сети, разбор `netsh wlan`, SDR-конфиг Valve, классификатор вылетов, анализ логов | Linux, .NET 8 | все проходят |
| Сборка self-contained single-file `Dota2Optimizer.exe` (win-x64) | Linux, кросс-сборка | собирается |
| Сборка `Setup.exe` (Inno Setup 6.4.3) | Linux + Wine | собирается |
| Тихая установка `Setup.exe /VERYSILENT /ALLUSERS` | Wine 9 | файлы, ярлык и деинсталлятор на месте. Установка «для текущего пользователя» под Wine не проверяется: Wine не поддерживает папку `{autopf}` пользователя (FOLDERID_UserProgramFiles), в Windows она есть |
| Смоук-тест UI: все вкладки открываются, сканирование, диагноз, план, dry-run, применение, одиночный откат, «Откатить всё» | Wine 9 + Xvfb, фейковая установка Steam/Dota 2 | dry-run не меняет файлы (`cmp`); после применения меняются ровно 5 ключей video.txt (основной и облачный), строка запуска в localconfig.vdf, значения HKCU; после отката оба video.txt и localconfig.vdf совпадают с оригиналом **байт в байт**, значения реестра восстановлены |

Wine — не Windows. Под ним нет WMI (.NET Framework), реального GPU-драйвера, `powercfg`, точки восстановления и UAC. Смоук-тест доказывает, что UI грузится, а логика файлов, реестра и отката работает на настоящем exe. Он **не заменяет** проверку на реальной Windows. Найденные под Wine ошибки исправлены: дублирующийся ключ ресурса XAML, привязки команд, падение сканера при отсутствии `powercfg` или WMI, классификация старых GTX 4xx/5xx.

## Ручная проверка в VM (Windows 10 22H2 и Windows 11 24H2/25H2)

Подготовка: чистая VM, Steam + Dota 2 (достаточно один раз запустить игру, чтобы появился `video.txt`), включена «Защита системы» на диске C:. Перед началом сделайте снимок VM.

Для каждого шага: dry-run → применить → проверить → откатить → проверить, что вернулось исходное значение.

| # | Твик | Проверка «применено» | Проверка «откачено» |
|---|---|---|---|
| 1 | Пресет video.txt | `game\dota\cfg\video.txt` (и `userdata\<id>\570\remote\cfg\video.txt`, если есть): изменились только ключи из отчёта, кодировка и CRLF сохранены. В игре настройки совпадают с пресетом | `fc /b` с копией из `%LOCALAPPDATA%\Dota2Optimizer\backups\<id>` |
| 2 | Параметры запуска | При запущенном Steam — статус «Сейчас недоступно» и строка для копирования. При закрытом Steam — после запуска Steam строка видна в свойствах Dota 2 | Строка в свойствах вернулась к прежней |
| 3 | Предпочтение GPU (ноутбук iGPU+dGPU) | Параметры → Дисплей → Графика → dota2.exe = «Высокая производительность»; после «Пересканировать» при запущенной игре в паспорте указана дискретная карта | Значение `HKCU\Software\Microsoft\DirectX\UserGpuPreferences\<путь>` удалено или вернулось к прежнему |
| 4 | План питания | `powercfg /getactivescheme` = 8c5e7fda… | Активен прежний план |
| 5 | Фоновая запись Game Bar | `HistoricalCaptureEnabled` = 0, в Game Bar «Записать последние моменты» выключено | Значение = 1 |
| 6 | Игровой режим | `AutoGameModeEnabled` = 1 | Прежнее значение |
| 7 | FSO (спорно) | Свойства dota2.exe → Совместимость → «Отключить оптимизацию во весь экран» отмечено | Флаг снят, прочие флаги совместимости на месте |
| 8 | HAGS (вручную) | UAC-запрос; `HwSchMode` изменён; после перезагрузки статус в Параметры → Дисплей → Графика | Прежнее значение после перезагрузки |
| 9 | Приоритет IFEO (спорно) | UAC; в Диспетчере задач у dota2.exe приоритет «Высокий» | Значение `CpuPriorityClass` удалено |
| 10 | Точка восстановления | В «Восстановление системы» появилась точка «Dota 2 Optimizer» (если за сутки других точек не было) | — |
| 11 | DNS | UAC; `ipconfig /all` показывает новый DNS | Вернулся DHCP или прежние статические адреса |
| 12 | Кеш шейдеров | Выбранные папки опустели (занятые файлы пропущены и посчитаны) | Не откатывается намеренно, кеш пересоздаётся |
| 13 | Проверка файлов / кеш загрузки Steam | Открылось окно Steam | — |
| 14 | Сброс сетевого стека | UAC, просьба перезагрузиться | Не откатывается (сказано в диалоге) |
| 15 | Замер FPS | Dota 2 в демо героя → «Замер «до»» → UAC → через N секунд результат, файл CSV в `%LOCALAPPDATA%\Dota2Optimizer\benchmarks` | — |
| 16 | «Откатить всё» | После шагов 1–9 и 11 всё возвращается; админские наборы — одним UAC-запросом | Сравнить с исходным снимком |
| 17 | Отказ в UAC | Нажать «Нет»: админские пункты в отчёте как пропущенные, пользовательские применены, ничего не сломано | — |
| 18 | Сбой посреди применения | Сделать `video.txt` недоступным для записи (запретить запись в ACL) → применить → в отчёте ошибка, уже сделанные шаги этого пункта откачены | — |

Дополнительно:
- **Вылеты:** вызвать TDR в VM нельзя. Проверяется на реальной машине или через синтетическое событие: `eventcreate /T ERROR /ID 1000 /L APPLICATION /SO "Application Error" /D "dota2.exe"` (классификатор полей не увидит и покажет общий «Вылет Dota 2»).
- **Сеть:** тест на Wi-Fi и на кабеле; выключить роутер посреди теста — вердикт «Проблема у вас».
- **Установщик:** Setup.exe ставится без прав администратора в `%LOCALAPPDATA%\Programs\Dota2Optimizer`; удаление оставляет `%LOCALAPPDATA%\Dota2Optimizer` (бэкапы).
